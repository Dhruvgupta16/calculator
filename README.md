# Simple Team Calculator

Basic calculator project using Git team workflow and JavaScript.

## Questions

### Q1: Git operations in a team
- `git checkout -b <branch-name>`: make new branch
- `git add .` and `git commit -m "msg"`: commit changes
- `git checkout main` and `git merge <branch-name>`: merge to main
- `git push origin <branch-name>`: push branch to GitHub

### Q2: Team working on separate branches and merging into main
- Worked on separate `js-calc` branch to make JavaScript calculator
- Merged `js-calc` branch into `main` branch

### Q3: JavaScript calculator with VS Code Git tools
- Open folder in VS Code
- Open Source Control tab (`Ctrl + Shift + G`) to see changes, stage, and commit
- Check current branch from bottom left corner of VS Code
- Open `index.html` in browser to run calculator
